# IDE Workflow Integration

Six-task project exploring AI-assisted development: from IDE fundamentals to building a mini agentic app with Copilot and Cursor.

Holberton School France · June 2026

## Tasks

| Task | Topic |
|------|-------|
| Task 0 | IDE fundamentals — what is an IDE, how AI helps beginners |
| Task 1 | VSCode + GitHub Copilot — setup, inline completions, chat |
| Task 2 | Completion vs chat modes — differences and use cases |
| Task 3 | Agent mode — autonomous multi-file edits and tool calls |
| Task 4 | Cursor IDE — Composer mode, codebase-aware completions |
| Task 5 | Mini app — build a small project with AI assistance |
| Task 6 | The trap — when AI tools mislead or hallucinate |

## Tools compared

```
VSCode + GitHub Copilot          Cursor IDE
─────────────────────            ──────────────────────────
Inline autocomplete              Composer mode (multi-file)
Chat panel (ask / explain)       @Codebase context
Agent mode (tool calls)          Tab completion
Refactor suggestions             Apply changes across files
```
